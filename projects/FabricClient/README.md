# FClient

A Minecraft 1.21.11 Fabric client base built with Mojang mappings.

## Features

- Module Manager
- AutoSprint Module (example module)

## Modules

- Name = AutoSprint
- Description = Automatically sprints for you
- Keybind  = V

You can easily add more modules using the ModuleManager

## Requirements

- Minecraft 1.21.11
- Fabric Loader
- Fabric API
